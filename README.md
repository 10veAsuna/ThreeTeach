# 彼此的路 · Paths We Share

《彼此的路》是围绕「同行」制作的三教杯 Game Jam 解谜游戏。玩家轮流控制 A 和 B。每次踏上同伴的脚印，落脚处都会变成自己的颜色，成为对方下一次可以走的路。两人各自到达出口，才能一起过关。

五章主线依次是初见、薄冰、来信、回声和同行。可以在「选关 → 机关练习」单独熟悉转桥、回放、换位等机关。

## 开始游玩

拿到 Windows 游戏包后，解压整个文件夹，再双击顶层的 `GameJam.exe`。

| 按键 | 操作 |
| --- | --- |
| 方向键 / WASD | 移动 |
| Tab | 切换角色 |
| E | 操作机关。转桥、换位和回放先预览，再按 E 确认 |
| Z | 撤销上一步 |
| H | 查看建议的下一步 |
| F1 | 查看当前角色可以走的位置 |
| L | 切换脚印传送连线的显示方式 |
| R | 请求重新开始本关 |
| Esc | 暂停或返回 |
| M | 切换音乐。暂停菜单中也可独立切换音效 |

章节解锁、回响和音频设置会自动保存。从主菜单继续时，会从未完成章节的起点开始。

## 制作与素材

- 游戏策划、关卡、程序、美术和音频由《彼此的路》项目团队制作。
- 游戏使用 Unreal Engine，场景中的基础几何体来自引擎自带的 BasicShapes。
- 背景音乐和音效由项目代码合成。
- 界面字体为 MiSans、Noto Sans SC 和 Noto Serif SC。字体名称及授权来源见 [字体说明](Content/OneStep/Fonts/README.md)。

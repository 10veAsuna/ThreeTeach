# 《彼此的路》试玩记录表

每轮记录版本、窗口分辨率与存档状态。盲测请使用空白存档，把玩家留在主菜单，然后观察。除非对方已经无法继续，先让界面、说明和 H 提示回答问题。

| 观察场景 | 通过条件 | 结果 |
| --- | --- | --- |
| 初见，第一次移动和换人 | 能看出 A 留下的蓝印可以供 B 使用。借路后能说出 B 为 A 留下了什么 | 待真人盲测 |
| 薄冰，第一次滑行或离开薄冰 | 知道滑行去了哪几格，知道薄冰离开后才消耗步数 | 待真人盲测 |
| 来信，等待寄印 | 能找到发送端、接收端和缺少的条件 | 待真人盲测 |
| 回声，录制与回放 | 能把录下的方向和落点编号对上。回放失败时能找到挡住的位置 | 待真人盲测 |
| 同行，路口与延迟送达 | 能分清巡逻要经过哪一格，以及任意角色移动都能推进等待中的传送 | 待真人盲测 |

每位试玩者记录第一次卡住的位置、是否使用 H，以及他用自己的话复述的规则。优先处理两人都遇到的问题。

提交前使用最终 Windows 包再走一遍下表。编辑器测试只能覆盖其中一部分。

| 检查项 | 通过条件 |
| --- | --- |
| 新机器启动 | 解压后运行顶层 EXE，正常显示中文与场景，看得到主菜单 |
| 五章进度 | 每关完成后解锁下一章。重启进入正确章节。通关后可从主菜单重玩 |
| 机关练习 | 从选关进入单独的练习页，完成练习后返回练习页 |
| 失误恢复 | 撤销恢复脚印、站位和机关状态。取消重开或返回时保留当前局面，确认后保留已解锁章节与回响 |
| 提示和连线 | H 给出可执行的一步，F1 预览可走格，L 可切换模式，等待中的传送在换人后仍可辨认 |
| 窗口尺寸 | 1280×720、1024×576 和常用全屏尺寸下，检查中文、落点编号、NEXT、WAIT 和底部提示是否互相遮挡 |
| 声音 | 音乐和音效可独立关闭，重启后保留。普通章节与练习关的通关声可在离开结算页后自然收尾 |
| 结尾 | 第五章进入「观看结尾」后完整播放收束乐句，脚印依次点亮，两人汇合后可以选关或返回菜单 |

# 《彼此的路》提交页素材

**标题**　彼此的路 / Paths We Share

**一句话简介**　你只能踩同伴的脚印，而你的每一次落脚，都会给同伴留下一步。

**作品介绍**　两位旅人在断桥与石板之间寻找出口。玩家轮流控制两人，在狭路上给彼此让位，把脚印寄给对岸的同伴，或录下自己的步伐，让另一个人沿着同样的节奏前进。五段旅程里，每个人既是跟随者，也是为同伴留下路的人。

**平台与游玩方式**　Windows PC，单人双角色，键盘操作。两位角色均抵达各自的出口时完成关卡。

**主题阐释**　「同行」体现在每一次落脚。对自己来说已经走过的格子，对同伴来说是刚刚出现的新路。玩家得反复判断该自己走，还是先给对方留下可以走的位置。

**截图取景**　优先用第三章「来信」或第五章「同行」的实机画面。画面中应同时出现蓝橙两人、两种脚印和一组清楚的传送连线。

**短录屏取景**　用第一章「初见」，从 A 向右走并踏入上方侧格时开始。接着切到 B 向左走两格，录到蓝印变成橙印。字幕依次写「A 留下蓝印」「B 借路」「B 留下回程的橙印」。成片控制在约 8–12 秒，避免先播放长菜单。

**署名**　作品团队为《彼此的路》项目团队。正式提交时以赛事报名表中的姓名和分工为准。素材来源采用 [玩家说明中的制作与素材](../README.md#制作与素材)。

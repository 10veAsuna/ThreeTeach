# UI fonts

This folder contains free, redistributable font files used by the game UI.

- `MiSans-Regular.otf`
- `NotoSansSC-Regular.otf`
- `NotoSansSC-Bold.otf`

MiSans is used as the fantasy-RPG-style body font under Xiaomi's published
MiSans font usage terms.

Noto Sans SC is distributed under the SIL Open Font License 1.1:
https://openfontlicense.org/

- `NotoSerifSC-VF.ttf`

Noto Serif SC is distributed under the SIL Open Font License 1.1:
https://github.com/notofonts/noto-cjk

These fonts are used as a legally distributable, fantasy-RPG-friendly
alternative. Genshin Impact's proprietary font files are not included.
